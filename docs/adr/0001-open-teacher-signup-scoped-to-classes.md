# Teachers sign up freely, but only see the Classes they teach

Anyone with an email address can create a Teacher account, so other teachers can start using the app without asking us first. In return, access is scoped per Class: a Teacher sees and manages only the Classes they created or were linked to, together with those Classes' Tasks, Projects and Reviews; all Teachers of a Class are equal. Students never need an email or password.

## Considered Options

- **An approved list of Teachers**, managed by an admin — rejected: someone would have to approve every new teacher, and "admin" is a role the app does not otherwise need.
- **Every Teacher sees everything** (how the five of us worked during the demo) — rejected for real use: with open sign-up, every new Teacher would see every school's children's names and work.

## Consequences

- Every access rule for Classes, Rosters, Tasks, Projects, group membership, Reviews and Reference Maps must be scoped to "a Teacher of this Class", not "any Teacher".
- A Task set for several Classes is visible to the Teachers of any of them; a Guest's Project belongs to the Task it was made for.
- The five demo accounts are linked to TG1 once, by hand. There is deliberately no in-app way to add or remove another Teacher from a Class yet.
